# samueledet.github.io

Personal website of Samuel A. Edet, PhD. It is a static site (plain HTML, CSS and a few lines of JavaScript) with no build step.

- `index.html`: all content
- `styles.css`: layout, plus light and dark themes
- `site.js`: theme toggle
- `photo.jpg`: portrait
- `notes/`: Market & Policy Notes, the articles section (`notes/index.html` lists them; one HTML file per article)

To update a section, edit `index.html` and push. GitHub Pages republishes within a minute or two.

To add a Market & Policy Note, copy `notes/digital-adoption-africa.html`, change the text, and add a card for it in `notes/index.html` (and in the Market & Policy Notes teaser on `index.html` if it is the latest).
